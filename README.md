# Power BI Practice: Data Job Postings (Guided Course Projects)

## About this project
This is a **learning/practice project** built while following [Luke Barousse's "Power BI for Data Analytics - Full Course for Beginners"](https://www.youtube.com/watch?v=FwjaHCVNBWA) on YouTube. I'm using it to build hands-on Power BI skills alongside my primary BI tool, Tableau.

This is **not an original independent analysis**. The dataset, business questions, and most chart designs come directly from the course. Each section's README notes what I followed as-is versus what I changed or added myself.

## Dataset
`job_postings_flat`: a global data-job-postings dataset (about 479,000 postings, used throughout the course) containing fields such as `job_title`, `job_country`, `salary_year_avg`, `salary_hour_avg`, `job_skills`, `job_work_from_home`, `job_no_degree_mention`, and `job_posted_date`.
